# Shop product art source record

Generated: 2026-08-22

These 16 transparent PNG masters were generated specifically for the project
with the OpenAI image generation capability in Gavin Gao's Codex desktop
workspace. No external image, third-party character, brand, logo, font, stock
asset, or artist-name style prompt was supplied.

All prompts shared these production constraints:

- finished creamy-cute watercolor rendering aligned with the project's Golden
  Set;
- a centered, intact product with transparent background and no UI panel;
- fresh cream, apricot, coral, mint, and sky-blue accents without a yellow wash;
- no text, watermark, logo, flat vector construction, geometric placeholder,
  pixel art, hard black outline, or plastic 3D look.
