# Freestanding Wind Chime Redraw - 2026-08-13

This source image was generated specifically for Petopia with OpenAI image
generation. Its only visual references were Petopia-owned yard decoration art,
the Golden Set palette, and the existing wind-chime item description.

- `windchime_freestanding_magenta.png` is the retained chroma-key source.
- The production asset is
  `assets/art/world/decor/deco_windchime_shiny.png`.
- Production processing removed the chroma background, cleaned edge spill,
  preserved the complete hook and stone base, and resized the result to a
  transparent 256x512 canvas with safe margins.
- No third-party stock image, character, brand, logo, font, texture pack, or
  external reference image was used.

The finished prop is intentionally freestanding so its visible support and
ground contact remain physically understandable in every yard theme.
