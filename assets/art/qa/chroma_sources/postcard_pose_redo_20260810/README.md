# Postcard Pose Redraw Provenance - 2026-08-10

These chroma-key source sheets were generated specifically for Petopia with
OpenAI image generation. The only visual references were Petopia-owned pet
prototypes and the project's Golden Set art direction. No third-party stock
art, commercial character, brand, font, or living-artist style reference was
used.

The sheets cover all eight postcard poses for the eleven non-cat species, plus
targeted replacement sheets for Starbug's first four poses and Snake's camera
pose. Production PNGs under `assets/art/postcards/poses/` were extracted,
reframed, and checked for complete anatomy, transparent margins, watercolor
detail, and pose semantics. Runtime WebP files are deterministic derivatives.

These source sheets are QA/provenance records and are not bundled in the app.
