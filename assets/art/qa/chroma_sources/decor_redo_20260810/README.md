# Decor Redraw Provenance - 2026-08-10

These chroma-key masters were generated specifically for Petopia with OpenAI
image generation. The only visual references were the Petopia-owned legacy
wildflower planter and mossy mushroom stool, used to preserve their established
object identity, palette, viewpoint, and creamy watercolor direction.

Both decorations were fully regenerated after runtime review found detached
footer fragments in the legacy transparent PNGs. The replacements keep the
complete intended objects while removing the unrelated semicircular and curved
remnants rather than hiding them through layout clipping.

No third-party stock art, commercial character, brand, font, or living-artist
style reference was used. These source masters are QA/provenance records and
are not bundled in the app.
