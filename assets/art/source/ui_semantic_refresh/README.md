# Semantic UI Icon Refresh

Generated on 2026-08-23 for Hearth & Tails with OpenAI image generation in
the project owner's Codex workspace. The prompts used only the project's own
Golden Set, cream watercolor palette, and product semantics. They did not use
third-party images, characters, brands, logos, fonts, stock assets, or artist
names.
