# Home menu icon source record

Generated: 2026-08-22

These nine transparent PNG masters were generated specifically for Hearth &
Tails with the OpenAI image-generation capability in Gavin Gao's Codex desktop
workspace. Their visual references were limited to the project-owned Golden
Set, existing watercolor UI palette, and the feature each icon represents.

- No third-party image, stock asset, character, brand, logo, font, texture pack,
  or artist-name style prompt was supplied.
- Each master keeps the complete painted subject inside a transparent safety
  margin and contains no baked text.
- Runtime icons are the corresponding 96px files under `assets/art/ui/` named
  `ui_icon_home_{journal,album,petdex,visitordex,achievements,shop,decorate,settings}.png`.
- `nav_menu_master.webp` is the compact handbook/menu source. Its 96px runtime
  derivative is `assets/art/ui/ui_icon_nav_menu.png`; the simplified silhouette
  and three page tabs are designed to remain legible at the 22px home-card size.
- The masters and runtime derivatives are project assets governed by the
  repository's `ASSET_LICENSE` and release rights records.
