## 📌 1.0 审核全过程（教训归档）

| 时间 (UTC) | 事件 |
|---|---|
| 08-27 06:52 | 1.0 (build 40) + 4 IAP 提交审核 |
| 08-27 → 09-01 | `WAITING_FOR_REVIEW` 排队 **90 小时** |
| 09-01 | `IN_REVIEW` → **`REJECTED`**，Guideline **2.1(b) Information Needed** |
| 09-01 09:45 | 解决中心回复五步定位路径 |
| 09-01 09:49 | Apple 将其放回队列（**无需点「重新提交」**，该按钮始终禁用） |
| 09-02 | `IN_REVIEW` → `PENDING_DEVELOPER_RELEASE` → 手动发布 → `READY_FOR_SALE` |

**拒审原因**：审核员找不到内购。全新安装时通往支持页的唯一路径是
**设置页最底部**（4 层深，压在「导出诊断信息」「报告问题」之下），
而主菜单里有个显眼的「商店」通向暖绒软通货商店（满屏"暖绒不足"）。
审核员在那里找付费商品，合理地判定"定位不到内购"。
另两个支持页入口都要求**已经买过**，构成先有鸡还是先有蛋。

**处理**：回复解决中心说明路径即可，**未改一行代码、未重打一个包**。
回复全文见 `review-reply-2.1b.md`。

**教训**：
1. `2.1(b) Information Needed` 属信息补充，回复即复审，不要去点「重新提交」（也点不了）
2. **不要点「取消提交」**——会撤掉整条提审单，排队位置从头开始
3. 付费入口的可发现性要按"审核员第一次打开 App"的标准检验；
   审核员找不到 = 用户也找不到，这不只是审核问题
4. 首审排队可能长达 90 小时，信息补充后的复审明显更快（< 24 小时）
