# 主题视觉冲击力改造 To-Do（Codex）

> 背景：现有 12 套主题中 6-7 套日间版高度同质（绿草地+拱门+白围栏，区别仅边缘植物），缩略图下无辨识度。
> 目标：每套主题**一眼可辨、有记忆点**，并与来客概率加成（visitorProbBonus）形成"视觉↔玩法"呼应。
> 分两批：**批次 A = 现有同质主题美术返工**（替换同名资产，零代码改动，可上架前做）；**批次 B = 新增强特征主题**（含少量代码，v1.x/付费候选，本单只做设计定稿不实装）。

## 全局硬约束（每张图必须满足）

1. **构图分带**：画面**中下 55% 是可用院子地面**（草地/沙地/石面），保持大面积留白——宠物、摆件、来客、食盆全在这里活动，不得有大型物体侵入摆放带（摆放带定义见 `integration_test/yard_home_visual_test.dart` 的 ground bands）。**主题特征元素集中在上 1/3 与左右边缘**。
2. **四图一套**：竖版日/夜 `yard_theme_<slug>_bg[_night].webp`（1290×2796）+ wide 日/夜（`assets/runtime/yard/themes/wide/`，2732×2048）。夜间版是同一场景的入夜状态,不是换构图。
3. **上 1/3 即预览带**：商店预览按 W4 修复后对齐顶部裁切——特征元素放上 1/3 等于同时把商店卡预览做对，交付前用商店卡尺寸（约 4:1 横带）自检一次。
4. 水彩风格对齐 `assets/art/samples/` Golden Set；文件体积对齐现有主题（无损 WebP，单张 ≤1MB 量级）；`provenance.json` 同步登记。
5. **铁律**：批次 A 只替换 `assets/art/world/themes/` 与 `assets/runtime/yard/themes/wide/` 下的同名文件 + 重烘 manifest；不改 slug、不改 shop_items.json、不改代码、不动其他资产。
